# Задание 5. Курсы двух базовых валют

Файл программы: [Задание 5.py](<Задание 5.py>).

Программа на Tkinter позволяет выбрать две базовые валюты и одну целевую.
По кнопке «Получить курсы обмена» она получает ответы JSON и показывает оба
курса в одном окне. По умолчанию выбраны EUR, USD и RUB.

## Запуск

Нужен Python 3 с Tkinter. В терминале из папки репозитория выполните:

```powershell
python -m pip install -r requirements_task5.txt
python "Задание 5.py"
```

Для получения курсов требуется интернет.

## Как работает exchange()

1. Считывает коды двух базовых валют и целевой валюты из выпадающих списков.
2. Проверяет, что все валюты выбраны.
3. В цикле отправляет отдельный запрос для каждой базовой валюты.
4. Преобразует ответ JSON в словарь Python командой `response.json()`.
5. Получает нужный курс из `data['rates'][target_code]`.
6. Собирает две строки вида `1 EUR = … RUB` и `1 USD = … RUB` и выводит их вместе.

При ошибке одного запроса доступный курс всё равно отображается, а рядом
появляется сообщение об ошибке второго. Обработаны сетевые ошибки, неверный
JSON и некорректный ответ сервиса. Установлен `timeout=10` для каждого запроса.
Запросы последовательные: во время ожидания сети интерфейс временно не отвечает.

Источник курсов: [ExchangeRate-API](https://www.exchangerate-api.com).
[Документация JSON API](https://www.exchangerate-api.com/docs/free).
