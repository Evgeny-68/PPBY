# Задание 6 — курсы криптовалют к доллару США

Приложение на Python и Tkinter показывает **BTC, ETH, SOL, XRP и DOGE**:
цену последней сделки на Kraken, минимум и максимум за последние 24 часа.
Все пять пар относятся к USD и загружаются одним запросом JSON.

## Почему выбран Kraken

Сравнены CoinGecko, CoinPaprika, Coinbase Exchange и Kraken. Для этого проекта
выбран **Kraken**: публичный запрос не требует аккаунта или ключа, позволяет
получить несколько USD-пар одновременно, а OHLC API подходит для добавления
графиков в итоговой работе. Цены относятся к сделкам на конкретной бирже.

- [Kraken — Ticker](https://docs.kraken.com/api-reference/market-data/get-ticker-information).
- [Kraken — публичный доступ](https://support.kraken.com/articles/360000919986-public-endpoint-examples-you-can-try-them-directly-in-a-web-browser-).
- [Kraken — OHLC](https://docs.kraken.com/api-reference/market-data/get-ohlc-data).

Сравнение альтернатив и ограничения приведены в ТЗ. История OHLC ограничена
720 последними точками, поэтому для длительной истории в будущем понадобится
собственное хранение или другой источник. Клиент API отделён от интерфейса,
чтобы заменять источник без переписывания таблицы.

## Запуск

Нужен **Python 3.10 или новее** с Tkinter и интернет для получения данных.
Скачайте весь проект или положите рядом два файла: `Задание 6.py` и
`crypto_api_task6.py`. Файл зависимостей также должен быть в текущей папке.

Откройте терминал в папке проекта:

```powershell
python -m pip install -r requirements_task6.txt
python "Задание 6.py"
```

После запуска котировки загружаются автоматически один раз. Кнопка «Обновить»
повторяет запрос. Флажок включает обновление каждые 60 секунд; по умолчанию
он выключен. Минимальный интервал между запросами — 5 секунд.

Сеть работает в фоновом потоке, поэтому окно не зависает. При ошибке последняя
успешная таблица и прежнее время получения сохраняются, а строка состояния
предупреждает об устаревших данных. До первого успеха в таблице стоят тире.
Время показано в МСК и обозначает получение данных приложением, а не время сделки.

## Проверки

```powershell
python -m unittest -v test_task6
```

Тесты не требуют интернета и используют подготовленные JSON-ответы. Проверяются
сопоставление пяти валют, поля цены и диапазона за 24 часа, HTTP/JSON/API-ошибки,
тайм-аут, пропущенные пары, некорректные числа, очередь результатов, ограничение
повторных запросов и сохранение таблицы при ошибке. Данные тестов условные.
