# Задание 6 — курсы криптовалют к USD и USDT

Приложение на Python и Tkinter показывает **BTC, ETH, USDT, GRAM, BNB, SOL, XRP и DOGE**:
цену последней сделки на **Bybit Spot**, минимум и максимум за последние 24 часа.
Один публичный запрос JSON обновляет две вкладки: **USD — доллар США** и
**USDT — Tether**. В каждой вкладке восемь строк; значения появляются только
для прямых пар из ответа API. GRAM — актуальный тикер бывшего TON на Bybit.

Проверка 12 ноября 2026 года подтвердила:

| Валюта цены | Прямые пары |
| --- | --- |
| USD | BTCUSD, ETHUSD, USDTUSD |
| USDT | BTCUSDT, ETHUSDT, GRAMUSDT, BNBUSDT, SOLUSDT, XRPUSDT, DOGEUSDT |

**USDT не приравнивается к USD.** Курс USDT/USD берётся с рынка, без подстановки 1.
Отсутствующая в ответе пара помечается «Нет данных по паре»; её цены и диапазон
не рассчитываются из других инструментов. USDT/USDT обозначается как валюта
котировки и не получает вымышленную рыночную цену. Новые прямые пары этих
активов к USD/USDT появятся в таблице, если API начнёт их возвращать.

## Почему выбран Bybit

После сравнения CoinGecko, CoinPaprika, Coinbase, Kraken, Bybit, OKX, BingX
и Gate прежний клиент Kraken заменён на **BybitClient**. Выбранный публичный
запрос не требует аккаунта или ключа и возвращает несколько спотовых пар
одновременно. Клиент API отделён от интерфейса.

`GET https://api.bybit.com/v5/market/tickers?category=spot` возвращает
`retCode`, `result.category` и `result.list`. Проверяется именно категория
`spot`, затем используются `lastPrice`, `lowPrice24h`, `highPrice24h`.
Данные контрактов и индекс `usdIndexPrice` не используются.

- [Bybit — Ticker](https://bybit-exchange.github.io/docs/v5/market/tickers).
- [Bybit — валюты и статус инструментов](https://bybit-exchange.github.io/docs/v5/market/instrument).
- [Bybit — прямые спотовые пары к USD](https://www.bybit.com/en/press/post/bybit-launches-usd-trading-pairs-simplifying-usd-on-ramp-for-traders-blt8cdc9184fde4695e).

Успешный публичный запрос не подтверждает доступность регистрации, KYC или
торговли для конкретного пользователя. Региональные ограничения рассмотрены
в [сравнении площадок](docs/task6_exchange_review.md).

## Запуск

Нужен **Python 3.10 или новее** с Tkinter и интернет для получения данных.
Скачайте весь проект или положите рядом два файла: `Задание 6.py` и
`crypto_api_task6.py`. Файл зависимостей также должен быть в текущей папке.
Иконка окна находится в `assets/crypto.ico`: сохраните папку `assets` рядом
с программой. Путь определяется относительно файла программы, поэтому иконка
работает и при запуске из другой папки. Если файл отсутствует или платформа
не поддерживает ICO, приложение запускается со стандартной иконкой.

Откройте терминал в папке проекта:

```powershell
python -m pip install -r requirements_task6.txt
python "Задание 6.py"
```

После запуска котировки загружаются автоматически один раз. Кнопка «Обновить»
повторяет запрос для обеих вкладок. Переключение вкладок не обращается к сети.
Флажок включает обновление каждые 60 секунд; по умолчанию он выключен.
Минимальный интервал между запросами — 5 секунд.

Сеть работает в фоновом потоке, поэтому окно не зависает. При ошибке последняя
успешные таблицы и прежнее время получения сохраняются, а строка состояния
предупреждает об устаревших данных. До первого успеха в таблице стоят тире.
Время показано в МСК и обозначает получение данных приложением, а не время сделки.
При успешном частичном ответе отсутствующие пары очищаются; прежняя цена
не выдаётся за свежую. Пустой ответ или ответ без всех целевых пар считается ошибкой.

## Проверки

```powershell
python -m unittest -v test_task6
```

Тесты не требуют интернета и используют подготовленные JSON-ответы. Проверяются
разделение USD/USDT, рыночный USDT/USD, отсутствие прямых пар, частичные ответы,
категория spot, дубликаты пар, поля цены и диапазона, HTTP/JSON/API-ошибки,
тайм-аут, некорректные числа, очередь результатов, ограничение повторных
запросов и сохранение обеих таблиц при ошибке. Данные тестов условные.
