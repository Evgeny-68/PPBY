ИТОГОВАЯ АТТЕСТАЦИОННАЯ РАБОТА
«Разработка приложения для отображения курсов криптовалют»
Берсенев Евгений Юрьевич, 2026 год

Приложение «Динамика курсов» показывает восемь криптовалют в двенадцати
валютах, изменение и денежный оборот за 24 часа, график сравнения USD/EUR.
Источник биржевых данных — публичный Bybit Spot API; справочные фиатные
курсы — ExchangeRate-API. Расчётные значения помечены знаком ≈.

УСТАНОВКА И ЗАПУСК

1. Установите Python 3.10 или новее с Tkinter. При установке Python в Windows
   включите добавление Python в PATH. Для новых курсов необходим интернет.
2. Откройте терминал в папке комплекта. Установите зависимость:

   python -m pip install -r requirements_final.txt

3. Запустите приложение:

   python "Zadanie_final.py"

Если команда python не найдена, используйте py вместо python во всех
командах. Наличие Tkinter можно проверить командой python -m tkinter.
Программа не требует ключа API или регистрации на бирже.

В списках «Криптовалюта» и «Валюта» выберите нужную пару. Кнопка «Обновить»
запрашивает новые данные; автоматическое обновление можно включить отдельно.
График всегда сравнивает USD и EUR выбранной монеты. Стрелки ▲ и ▼ дополняют
цвет и знак изменения. Прочерк означает отсутствие показателя.

ПРОВЕРКА

В той же папке выполните:

   python -m unittest test_final

Автоматические тесты не требуют действующего API. В зафиксированном прогоне
успешно выполнены 112 тестов. Проверка работающего окна с реальным Bybit
описана отдельно в протоколе. Проверенная среда: Windows, Python 3.14.5.

USD и USDT различаются. Оборот относится к указанной паре Bybit, а не ко всем
сделкам с монетой на всех биржах. Валютный справочник обновляется раз в сутки.
При ошибке сети приложение сохраняет прежние данные с предупреждением;
после восстановления связи нажмите «Обновить».
